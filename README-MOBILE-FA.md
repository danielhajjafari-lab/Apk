# ساخت APK بدون کامپیوتر (با گوشی)

این پروژه می‌تواند در GitHub Actions روی فضای ابری کامپایل شود؛ برای دریافت APK لازم نیست کامپیوتر داشته باشید.

1. در مرورگر گوشی وارد github.com شوید و حساب بسازید/وارد شوید.
2. یک Repository جدید (ترجیحاً Private) بسازید.
3. فایل‌های پروژه را در ریشه repo بارگذاری کنید؛ باید `app/` و `build.gradle.kts` و `settings.gradle.kts` و پوشه `.github/workflows/` هم‌سطح باشند. از بارگذاری پوشه بیرونی اضافه پرهیز کنید.
4. به تب Actions بروید. گردش کار `Build Android APK` را انتخاب کنید و در صورت نیاز Run workflow را بزنید.
5. پس از موفقیت، در اجرای workflow بخش Artifacts، فایل `dakhlokharj-debug-apk` را دانلود و استخراج کنید.
6. APK را روی گوشی نصب کنید (ممکن است لازم باشد اجازه نصب برنامه از منبع مرورگر/فایل‌ها را فعال کنید).

این build cloud صرفاً فرایند ساخت را خودکار می‌کند. APK ساخته‌شده هنوز باید روی گوشی آزمایش شود. این پروژه مجوزهای SMS دارد؛ متن پیام فقط هنگام پردازش در حافظه استفاده می‌شود و در دیتابیس ذخیره نمی‌شود. با این حال، اعلان‌ها/مجوزها و الگوهای Regex را با پیامک‌های نمونه و غیرحساس آزمایش کنید.
