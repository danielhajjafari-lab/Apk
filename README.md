# دخل‌وخرج — پروژه Android (نسخه اصلاح‌شده سورس)

دفتر مالی شخصی فارسی با ذخیره محلی.

## امکانات موجود در سورس
- داشبورد درآمد و هزینه ماه جاری، مانده و خرج روز.
- ذخیره محلی تراکنش‌ها با Room.
- ثبت دستی درآمد و هزینه.
- الگوی Regex جدا برای واریز/برداشت هر بانک؛ گروه capture اول مبلغ است.
- SMS Receiver که متن پیام را فقط در حافظه پردازش می‌کند و متن پیام را در دیتابیس ذخیره نمی‌کند.
- اعلان برای باز کردن صفحه ثبت تراکنش؛ دسته‌بندی هزینه.
- سقف روزانه و هشدارهای ۸۵/۱۰۰ درصد، با جلوگیری از تکرار هشدار در همان روز.
- PDF گزارش ماه جاری از تراکنش‌های ماه جاری.

## ساخت APK
1. Android Studio و JDK 17 نصب کنید.
2. پروژه را در Android Studio باز کنید.
3. SDK 35 را نصب کنید و Gradle Sync انجام دهید.
4. روی گوشی مجوز SMS و اعلان را اعطا کنید.
5. Run یا Build APK را انتخاب کنید.

## مهم: این پروژه هنوز روی دستگاه واقعی یا با Gradle در این محیط کامپایل و تست نشده است
- الگوهای بانکی باید با نمونه واقعی پیامک هر بانک (پس از حذف اطلاعات شخصی) آزمایش شوند.
- دریافت پیامک به مجوزهای Android نیاز دارد و ممکن است در برخی دستگاه‌ها/تنظیمات باتری محدود شود.
- نسخه فعلی، متن پیامک را ذخیره نمی‌کند، اما Regexها به‌تنهایی تضمین نمی‌کنند که هر پیامک درست تشخیص داده شود. پیام‌های بانکی باید الگوهای دقیق و قابل آزمایش داشته باشند.
- گزارش PDF نسخه فعلی ساده است و برای تأیید شکل‌دهی کامل حروف فارسی، راست‌چین بودن و نمایش تمام صفحات باید روی دستگاه تست شود.
- ساخت خودکار و زمان‌بندی گزارش PDF ابتدای هر ماه هنوز کامل نشده است.
- APK آماده و تأییدشده ارائه نشده است؛ این فایل سورس پروژه است.
